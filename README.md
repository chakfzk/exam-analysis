# 평가분석 · Exam Analysis

**[웹사이트 열기](https://chakfzk.github.io/exam-analysis/)**

나이스 교과목별학생답정오표를 브라우저에서 분석하는 중학교 문항 분석 도구입니다. 별도 설치나 Streamlit 로그인 없이 사용합니다.

## 사용 방법

1. 같은 과목·같은 시험의 학급별 `.xlsx` 또는 `.xls` 파일을 선택합니다.
2. 성취수준별 인원, 과목총점 분포, 문항별 정답률과 보기 선택 비율을 확인합니다.
3. 정답률 순으로 문항을 정렬하거나 CSV로 요약 결과를 저장합니다.

‘예시 데이터로 먼저 둘러보기’는 실제 학생 정보가 없는 가상 자료입니다.

## 분석 기준

100점 만점의 **과목총점** 열을 사용합니다. 학생들의 상대적 순위나 백분위로 컷을 바꾸지 않습니다.

| 수준 | 점수 |
|---|---|
| A | 90 이상 |
| B | 80 이상 90 미만 |
| C | 70 이상 80 미만 |
| D | 60 이상 70 미만 |
| E | 60 미만 |

- 업로드한 시험 점수 기준의 분석용 구분입니다. 수행평가 등을 합산한 학기말 성취도와 다를 수 있습니다.
- 정답률과 보기 선택 비율의 분모는 해당 집단 전체 학생 수입니다. 무응답과 1~5 이외 응답은 오답으로 포함합니다.
- 나이스의 `.` 표시는 정답으로 처리합니다.
- 보기 선택 비율은 전체·A·B·C·D·E의 막대그래프로 표시하며 정답 보기는 금색으로 강조합니다. 학생이 없는 수준은 `—`와 ‘해당 학생 없음’으로 표시합니다.
- 각 문항에 정답률(0~1)과 변별도(-1~1)를 함께 표시합니다. 정답률은 백분율도 병기합니다.
- 변별도는 원본과 같이 총점 73·27백분위(선형 보간)를 기준으로 나눈 상·하위 약 27% 집단의 정답률 차이입니다. 동점자에 따라 집단 크기가 달라집니다. 컷이 같으면 상위 분류가 우선이며 한 집단이 비면 변별도를 계산하지 않습니다. A~E 고정분할점수 분류와는 별개입니다.
- 원본 나이스 양식의 문항번호·정답·배점 다음 행부터 학생 자료를 읽습니다. 첫 번째 시트를 사용하며, 두 번째 열의 반/번호와 과목총점을 확인합니다.
- 과목총점이 없는 학생 행은 제외하고 제외된 행 수를 표시합니다. 0~100점 밖의 총점은 오류로 안내합니다.
- 같은 문항번호와 정답을 가진 파일만 합칩니다. 파일당 최대 30MB입니다.

## 자료 처리

엑셀 읽기와 계산은 사용자 브라우저에서만 실행됩니다. 학생 파일을 서버에 업로드하거나 브라우저 저장소에 보관하지 않습니다. 이름과 반/번호는 분석 결과에 보관하지 않습니다. 새로고침 또는 ‘자료 지우기’로 분석 자료를 지울 수 있습니다. 사이트 접속 정보는 GitHub Pages의 정책을 따릅니다.

## 구성 / 배포

- `index.html`, `style.css`, `app.js`: 화면과 상호작용
- `analysis.js`: 자료 정리, A~E 분류, 정답률 계산
- `vendor/`: 로컬로 포함한 SheetJS CE 0.20.3 (Apache-2.0)
- `legacy/`: 이전 Python/Streamlit 버전. 웹 실행에는 사용하지 않습니다.

GitHub Pages의 `main` 브랜치, 루트 폴더(`/`)로 게시합니다. 빌드나 별도 서버가 필요하지 않습니다.

로컬 확인:

```sh
python -m http.server 8765
```

브라우저에서 `http://localhost:8765`를 엽니다.
